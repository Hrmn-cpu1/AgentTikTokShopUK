# TikTok provider boundary — UK, checked 2026-09-27

| Capability | Official surface | Project/account status | V0 actor |
| --- | --- | --- | --- |
| Creator affiliate product discovery | TikTok Shop Partner Center documents Creator Search Open Collaboration Product and related creator affiliate scopes. Affiliate APIs are inactive by default and require approval through a Partner or Account Manager. | **REQUIRES_APPROVAL / account access UNKNOWN** | Operator records product and reference manually. |
| Creator affiliate orders | Partner Center lists Search Creator Affiliate Orders with creator authorization and an affiliate scope. | **REQUIRES_APPROVAL / account access UNKNOWN** | Operator records order identity and evidence manually. |
| Direct video publication | TikTok Content Posting API documents Direct Post and `video.publish`, requiring app approval and user authorization. Unaudited clients are limited to private viewing. Its documented posting flow alone does not prove a TikTok Shop shoppable product link. | **REQUIRES_APPROVAL / Shop linkage UNKNOWN** | Human publishes in TikTok, then records real publication ID and evidence. |
| Publication observation | Content Posting API has status polling and webhooks for content uploaded through that API. This is not a general reader for arbitrary manual posts. | **SUPPORTED for approved API flow; unavailable to this app now** | Human verifies the manual video in TikTok. |
| Commission settlement / payout | TikTok Shop Partner Center describes UK CAP/TAP earnings and paid order exports, but those partner reports do not establish access to this creator account or a creator settlement API. Seller Finance API is not creator commission authority. | **UNKNOWN for this account** | Operator checks actual earnings and records amount with reference; cash arrival separately manual. |

Sources: [Affiliate integration](https://partner.tiktokshop.com/docv2/page/affiliate-integration), [Direct Post prerequisites](https://developers.tiktok.com/docs/en/content-posting-api-get-started), [Post status](https://developers.tiktok.com/docs/en/content-posting-api-reference-get-video-status), [UK CAP/TAP earnings](https://partner.tiktokshop.com/docv2/page/67e1390ae2bca304a1450a92).

**Engineering consequence:** no official TikTok request is sent by V0. An operator-entered reference is a manual assertion; the app cannot relabel it `OFFICIAL_API` or claim provider verification. Before implementing an API adapter, obtain the specific account's authorized scope, confirm the exact endpoint and response semantics, then prove intent → external effect → observation → reconciliation including ambiguous responses. Never infer a shoppable Shop attachment or commission settlement from a successful Content Posting response.
